# K-POP韓国語学習サイト

K-POP の歌詞を使って韓国語を学ぶための、ローカル実行前提の学習サイトです。

このアプリは単なる歌詞表示ページではなく、1 行ずつ意味を追いながら、

- 歌詞の原文
- カタカナ読み
- 日本語訳
- 一文ごとの解説
- 単語ごとの意味と分解
- 文法ポイント
- 曲別クイズ
- 横断的な単語帳
- 横断的な文法一覧

をまとめて見られる構成になっています。

## このサイトでできること

### 1. 曲一覧から学習したい曲を選ぶ

ホームでは、登録済みの曲をカード形式で一覧表示します。

- 曲名
- アーティスト名
- 曲の概要
- 収録単語数
- 収録文法数
- 行数
- タグ

が見えるので、学びたいテーマから曲を選びやすくなっています。

検索では次の情報を横断してヒットします。

- 曲名
- アーティスト名
- タグ
- 歌詞本文
- 日本語訳

### 2. 歌詞を 1 行ずつ詳しく読む

曲詳細ページは、左側が歌詞、右側が解説の 2 カラム構成です。

左側では各行を次の順番で表示します。

1. 読み方（カタカナ）
2. 原文
3. 日本語訳

右側では、選択した行に応じて次の情報を表示します。

- 直訳
- 一文の意味
- ニュアンス
- 歌詞全体の中での役割
- 文法ポイント
- その行に出てくる単語・表現

さらに、右側の単語・表現をクリックすると、下の単語詳細パネルで次のような情報を見られます。

- 表層形
- 原形
- 品詞
- 難易度
- 短い意味
- 詳しい意味
- 分解
- この歌詞の中での意味
- 関連語
- 例文

### 3. 単語帳として横断的に復習する

`単語帳` ページでは、全曲から集めた単語を一覧で検索できます。

絞り込み条件:

- テキスト検索
- 品詞
- 難易度
- 言語（韓国語 / 英語）
- 曲名

歌詞から出てきた単語を、曲をまたいで復習できるのが特徴です。

### 4. 文法を横断して確認する

`文法一覧` ページでは、各曲に埋め込まれた文法ポイントをまとめて確認できます。

検索対象:

- 文法名
- 意味
- 解説

また、曲ごとの絞り込みにも対応しています。

### 5. クイズで理解を確認する

`クイズ` ページでは、全曲のクイズをまとめて解くことができます。

対応している出題タイプ:

- 単語の意味
- 原形
- 文法の意味
- 穴埋め
- どの曲かを当てる問題

対応しているモード:

- 1問ごと採点
- まとめ採点
- 登録順
- ランダム出題

## どんな学習体験を目指しているか

このサイトは、「曲を聴いてなんとなく好き」で終わらせず、
「歌詞のどの表現がどういう意味で、どういうニュアンスで、どんな文法が使われているか」
まで追えるようにすることを目的にしています。

特に重視しているのは次の点です。

- 韓国語初心者でも、1 行ずつ意味を追えること
- 単語を辞書的に覚えるだけでなく、歌詞の中での意味をつかめること
- 同じ文法や表現を、別の曲でも見つけられること
- 自分専用の学習サイトとして曲データを増やしていけること

## データの作り

このサイトの中心は `Song` 型です。

1 曲ごとに、次のような情報を持ちます。

- 曲 ID
- タイトル
- アーティスト
- 難易度
- タグ
- 曲全体の概要
- 歌詞行データ
- 曲別クイズ

歌詞 1 行は `LyricLine` として管理され、そこにさらに

- 読み方
- 日本語訳
- 直訳
- 一文解説
- ニュアンス
- 歌詞中での役割
- 文法ポイント
- 単語トークン

が入ります。

単語 1 つは `Token` として持ち、必要に応じて

- 原形
- 品詞
- 難易度
- 分解
- 例文
- 関連語

なども追加できます。

## 曲データを増やす流れ

新しい曲を追加するときは、基本的に次の流れです。

1. 元テキストを用意する
   - 歌詞
   - 直訳 / 自然訳
   - 単語分解
   - 文法メモ
   - ニュアンス解説

2. 行データファイルを作る
   - 例: `src/data/songs/_iam-lines-all.ts`

3. 曲ファイルを作る
   - 例: `src/data/songs/ive-i-am.ts`
   - 概要、タグ、クイズ、必要なら読み方や区切りを追加する

4. 一覧へ登録する
   - `src/data/songs.ts`

5. 動作確認する
   - `npm run build`

この構成にしてあるので、1 曲ずつ着実に詳しくしていくことができます。

## 技術スタック

- React 19
- TypeScript
- Vite
- React Router DOM
- Tailwind CSS
- ESLint

バックエンドやデータベースは使っておらず、学習データはすべてリポジトリ内のファイルで管理しています。

## 開発コマンド

依存関係のインストール:

```bash
npm install
```

開発サーバー起動:

```bash
npm run dev
```

本番ビルド:

```bash
npm run build
```

Lint:

```bash
npm run lint
```
